WBot Assistant 0.11.0

流程独立环境托管与跨电脑部署
- Assistant 只负责校验、解压和运行流程，不创建虚拟环境、不安装依赖、不回退到宿主 Python。
- 支持 Studio 0.11.0 生成的 schemaVersion=2 完整环境包，包含 Windows x64 Python、标准库及项目依赖。
- 支持离线导入与 OC 下发；空白执行设备无需预先安装 Python 或登记项目目录。
- 每个流程版本独立保存环境，任务启动前校验文件完整性；升级 Assistant 保留流程环境。
- 可通过“托管流程”登记已有 .venv 项目；旧版纯代码包需要登记对应环境后才能运行。

浏览器扩展
- 设置新增 Chrome / Edge 安装引导、固定扩展目录、目录复制与扩展连接检测。
- 用户在浏览器扩展管理页完成“加载已解压的扩展程序”；不修改企业策略或个人资料。

兼容说明
- 完整环境包目前支持 Windows x64；需配套支持 schemaVersion=2 的 OC。
- Office、浏览器程序、系统驱动及 Playwright 浏览器缓存仍需在设备上另外准备。
- 已发布的旧流程不再使用 Assistant 共享 Python，请重新构建完整环境包或登记独立项目环境。
