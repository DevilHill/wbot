# 0.11.0

- 构建自动化发布包时携带项目独立 Python、标准库和已安装依赖，支持 Windows x64 跨电脑交付。
- 发布到 Assistant 0.11.0 后直接校验、解压并托管包内环境；通过配套 OC 可下发到空白执行设备。
- OC 发布采用流式上传，完整环境包支持最大 516 MiB；拒绝共享系统依赖、editable 和外部环境路径。
- 新格式需要 Assistant 0.11.0 及支持 schemaVersion=2 的 OC；原有代码包仍可配合本机项目环境托管。

# 0.10.0

- 新建自动化项目时创建项目专属 `.venv`，安装内置 WBot SDK 与依赖并记录精确版本。
- 自动生成输入/输出目录、VS Code 解释器与调试配置、依赖文件及环境重建说明。
- 示例入口支持本地直接运行；初始化不需要连接 Assistant，已有目录不会覆盖。

# 0.9.1

- 连接侧栏增加 Assistant 断开、重新连接和实例选择入口。
- 手动断开后暂停自动发现，重启 VS Code 后仍保持断开；Assistant 后台和 OC 绑定不受影响。
- 重连时重新读取服务与 OC 状态，清理过期元素和共享状态，阻止断开期间继续发送操作。

# 0.9.0

- 元素库、浏览器抓取和 XPath 校验统一由 Assistant 0.9.0 托管。
- 移除插件自建 Python 浏览器服务和启停命令，元素操作不受开发者 Python 配置影响。
- 浏览器扩展目录由 Assistant 准备，关闭 VS Code 后浏览器服务仍可用。
- Assistant 离线、版本过旧及端口被旧服务占用时给出具体提示。

# 更新记录
